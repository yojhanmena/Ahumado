# Ahumados del Fogón — Carta Digital

Carta gastronómica digital del restaurante **Ahumados del Fogón** (Quibdó, Chocó).
Construida con **HTML5, CSS3 y JavaScript Vanilla**. No requiere backend ni base de datos.

## 🚀 Cómo ejecutar

1. Abre la carpeta `AHUMADOS-DEL-FOGON` en Visual Studio Code.
2. Instala la extensión **Live Server**.
3. Clic derecho sobre `index.html` → **Open with Live Server**.

También puedes publicarlo en cualquier hosting estático (Netlify, Vercel, GitHub Pages, Hostinger, etc.).
